Canela — PRIMARY font (headings, page titles, editorial)
Licensed typeface by Commercial Type. Add web-licensed WOFF2 files only.

Required file names:

  Canela-Light.woff2          weight 300   (hero headings)
  Canela-Regular.woff2        weight 400   (page, section & category headings)
  Canela-RegularItalic.woff2  weight 400 italic
  Canela-Medium.woff2         weight 500+  (logo / any heavier usage — never bolder than Medium)

If your files are named differently (e.g. "Canela-Regular-Web.woff2"), rename them to
match, or update the @font-face rules in src/index.css.

Until these files exist, the site renders a TEMPORARY fallback (Cormorant Garamond).
That fallback is not Canela.
