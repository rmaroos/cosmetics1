Suisse Int'l — SECONDARY font (navigation, body, product names, prices, buttons, forms, labels)
Licensed typeface by Swiss Typefaces. Add web-licensed WOFF2 files only.

Required file names:

  SuisseIntl-Regular.woff2        weight 400   (body, inputs, footer)
  SuisseIntl-RegularItalic.woff2  weight 400 italic (optional)
  SuisseIntl-Medium.woff2         weight 500+  (nav, product names, prices, buttons, labels)

If your files are named differently (e.g. "SuisseIntl-Regular-WebS.woff2"), rename them
to match, or update the @font-face rules in src/index.css.

Until these files exist, the site renders a TEMPORARY fallback (Inter).
That fallback is not Suisse Int'l.
